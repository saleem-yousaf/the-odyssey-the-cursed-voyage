THE ODYSSEY — THE CURSED VOYAGE

1. Extract the ZIP into a folder.
2. Open index.html in a modern web browser.

The complete voyage works offline. The external link to Homer's Odyssey requires internet access.
Progress is stored in your browser when storage is available. Your current hosted-site progress is not included in this download.

Keep index.html, style.css, chapters.js and app.js together.
No installation or build is required. You can also serve these files using any static web server.
